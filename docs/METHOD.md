# Методика расчётов

## Обозначения

N - число участников. Для участника i:

- R+ и R- - полученные положительные и отрицательные выборы;
- S+ и S- - сделанные положительные и отрицательные выборы.

Все суммы считаются внутри группы, выбор самого себя не учитывается. C = N(N - 1) / 2 - число возможных пар.

Значения округляются до двух знаков, половина - от нуля: 0.875 → 0.88, -0.125 → -0.13.

## Персональные индексы

| Индекс | Формула |
|---|---|
| Ci+ | R+ / (N - 1) |
| Ci- | R- / (N - 1) |
| Ci | (R+ - R-) / (N - 1) |
| E+ | S+ / (N - 1) |
| E- | S- / (N - 1) |
| E | (S+ + S-) / (N - 1) |
| Куд | R+ / S+ (0, если S+ = 0) |

## Статусы

m+ - среднее число полученных положительных выборов в группе. Пороги округляются до целого, половина вверх.
Условия проверяются по порядку, срабатывает первое:

1. Изолированный: R+ = 0 и R- = 0.
2. Отвергаемый: R- > 0 и (R+ = 0 или R+ < round(m+ / 2)).
3. Звезда: R+ ≥ round(2 · m+).
4. Предпочитаемый: R+ ≥ round(1.5 · m+).
5. Пренебрегаемый: R+ > 0 и R- > 1.5 · R+.
6. Принятый: все остальные.

Перцептивный статус считается по тем же правилам по матрице перцептивных выборов.

## Групповые индексы

V+ и V- - число участников, у которых есть хотя бы одна взаимная положительная (отрицательная) связь.
M+ и M- - число взаимных пар. L+ и L- - всего сделанных выборов.

| № | Индекс | Формула |
|---|---|---|
| 1 | Ag - экспансивность группы | (L+ + L-) / N |
| 2 | Gg - взаимность | V+ / C; в скобках max(Gg, floor(L+ / 2) / C) |
| 3 | U - референтность | M+ / L+ |
| 4 | Kg - конфликтность | V- / C |
| 5 | R- - взаимность отрицательных выборов | 2 · M- / L- (без отрицательных выборов не рассчитывается) |
| 6 | Охват взаимными + | V+ / N |
| 7 | Централизация + | Σ(dmax - R+ᵢ) / (N - 1)², dmax - наибольшее R+ |
| 8 | Крупнейшая связная часть | доля участников в крупнейшей компоненте графа + выборов (направление не учитывается) и число компонент |
| 9 | Без положительных связей | доля тех, кто не сделал и не получил ни одного + |
| 10 | Противоречивые пары | Q / C, Q - пары «+ в одну сторону, - в другую» |
| 11 | Охват + | доля участников с R+ > 0 |
| 12 | Охват - | доля участников с R- > 0 |
| 13 | Охват взаимными - | V- / N |
| 14 | Только отрицательные | доля участников с R- > 0 и R+ = 0 |

Классические варианты Gg = M+ / C и Kg = M- / C показываются в пояснениях к индексам.

## Рекомендации

Каждая рекомендация появляется только при своём условии, порядок фиксирован:

1. Подгруппы: в сети + выборов не меньше двух компонент по 2 и более человека.
2. Нет положительных связей: есть участники без единого + в обе стороны. Иначе, если кто-то не получил ни одного +, вместо неё - совет о доступном участии для всех.
3. Нет взаимных +: есть участники без взаимной положительной пары.
4. Отрицательные выборы: есть хотя бы один -.
5. Противоречивые пары: есть хотя бы одна такая пара.

Если ни одно условие не выполнено, рекомендаций нет.

## Индивидуальная социограмма

Для участника и знака выбора (+ или -):

- узлы - сам участник и все, с кем у него есть связь этого знака в любую сторону;
- связи - все выборы участника и выборы к нему, а также выборы внутри этого круга, сделанные теми, кто сам выбрал участника (плюсом или минусом);
- взаимная пара рисуется одной толстой линией со стрелками с двух сторон.
