# Linx - обработка социометрии

Программа для Windows для проведения и обработки социометрии в любых группах: ввод выборов,
расчёт индексов и статусов, отчёты с социограммами, печать, выгрузка в Word и Excel.
Работает без интернета, все данные остаются на компьютере.

## Возможности

- Протоколы: создание, поиск и фильтры, дублирование, удаление.
- Ввод выборов списком или матрицей, перцептивные выборы (p), фото участников.
- Импорт списка или готовых выборов из XLSX и CSV (UTF-8 и Windows-1251).
- Персональные индексы, статусы, 14 групповых индексов, перцептивный блок.
- Общий и индивидуальный отчёты, социограммы взаимных выборов.
- Социограммы: перетаскивание узлов (раскладка сохраняется), масштаб, PNG, копирование в буфер.
- Чёрно-белый режим для печати: штриховки, пунктиры и разные обводки вместо цвета.
- Экспорт: печать и PDF, Word (.docx), Excel (.xlsx) с диаграммой и социограммами.
- Копирование любой таблицы отчёта в буфер (как таблица или картинка).
- Все тексты отчёта (пояснения, интерпретация, рекомендации) редактируются.
- Резервная копия всей базы одним файлом.

Формулы и правила описаны в [docs/METHOD.md](docs/METHOD.md).

## Скачать

Готовые файлы лежат в разделе [Releases](https://github.com/makulatury/linx/releases/latest)
(справа на главной странице репозитория). Откройте последний выпуск и в блоке «Assets» нажмите на нужный файл:
`Linx_1.0.0_setup.exe` (с установкой) или `Linx_1.0.0_portable.zip` (без установки).

## Две версии

| | С установкой | Без установки (переносная) |
|---|---|---|
| Файл | `Linx_1.0.0_setup.exe` | `Linx_1.0.0_portable.zip` |
| Как начать | запустить установщик | распаковать архив в любую папку или на флешку, запустить `Linx\Linx.exe` |
| Ярлык в «Пуск» | есть | нет |
| Удаление | «Параметры → Приложения» | удалить папку `Linx` |
| Где база | `%APPDATA%\com.makulatury.linx\data` | рядом с программой, в папке `Linx\Linx-данные` |

Обе версии умеют одно и то же. Установщику не нужны права администратора.
Переносную версию переносят вместе с папкой `Linx-данные` - в ней вся база.
Если в эту папку нельзя записывать (например, программа лежит в `Program Files`), программа предупредит
и временно сохранит базу в папке пользователя.

Где лежит база, всегда видно в разделе «Справка». Кнопка «Сохранить базу в файл» делает резервную копию,
«Загрузить из файла» восстанавливает её или переносит базу на другой компьютер.
Выгрузки (Word, Excel, PNG) сохраняются через обычное окно «Сохранить как».

Программа не подписана сертификатом, поэтому при первом запуске Windows может показать
«Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».

## Сборка

Один раз установить:

- Visual Studio Build Tools 2022 с компонентом «Разработка классических приложений на C++»
  (`winget install Microsoft.VisualStudio.2022.BuildTools`, затем в установщике выбрать этот компонент);
- Rust: `winget install Rustlang.Rustup`;
- Tauri CLI: `cargo install tauri-cli --version "^2" --locked`;
- Python 3. Node.js не нужен, WebView2 в Windows 10/11 уже есть.

Сборка обеих версий (из корня проекта):

```
python build_windows.py
```

Результат - в папке `release/` (в git не попадает): установщик и архив переносной версии.
Первая сборка идёт 5-10 минут и скачивает зависимости.

Как это устроено: интерфейс написан на HTML и JavaScript (`src/`), `build.py` собирает его в один файл
`dist/Linx.html`, а Tauri (`src-tauri/`) показывает его в окне программы и хранит базу на диске.
Для быстрой проверки без установщика: `cargo tauri dev` из папки `src-tauri`.

База на диске: `protocols\<id>.json` - по файлу на протокол, `settings.json` - настройки и тексты отчёта.
Переносная версия определяется просто: если рядом с программой есть папка `Linx-данные`, база хранится в ней.

Иконки собраны из `src-tauri/icons/linx.svg` (логотип «Тройка») командой `cargo tauri icon icons/linx.svg`
(лишние иконки для Android, iOS и macOS после этого можно удалить).

## Структура

| Файл | Назначение |
|---|---|
| `src/calc.js` | расчёты: матрица, индексы, статусы, рекомендации, индивидуальные социограммы |
| `src/storage.js` | слой хранения: в программе - файлы на диске через `src/native.js` |
| `src/native.js` | связь интерфейса с программой: хранение на диске, окно «Сохранить как», место базы |
| `src/importers.js` | чтение CSV и XLSX |
| `src/texts.js` | шаблоны текстов отчёта с подстановками |
| `src/graph.js` | социограммы и круговая диаграмма на SVG, PNG |
| `src/export.js` | сборка DOCX и XLSX (свой код, без библиотек) |
| `src/tablekit.js` | таблицы отчёта для буфера обмена и PNG |
| `src/app.js`, `editor.js`, `report.js`, `textsview.js` | интерфейс |
| `src/fixtures.js` | контрольная группа для тестов и примера |
| `src-tauri/src/lib.rs` | программа: команды хранения, запись файлов, выбор папки базы |
| `src-tauri/tauri.conf.json` | окно программы и установщик |
| `build.py` | сборка интерфейса в один файл |
| `build_windows.py` | сборка установщика и переносной версии |

## Тесты

`tests/test.html` - проверка расчётов на контрольных примерах. Запустите из корня проекта

```
python -m http.server 8765
```

и откройте `http://localhost:8765/tests/test.html`. В `tests/files/` лежат образцы файлов для проверки импорта.
