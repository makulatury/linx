# Linx - обработка социометрии

Офлайн-приложение для проведения и обработки социометрии в любых группах: ввод выборов,
расчёт индексов и статусов, отчёты с социограммами, печать, выгрузка в Word и Excel.
Работает без интернета и без сервера.

## Возможности

- Протоколы: создание, поиск и фильтры, дублирование, удаление.
- Ввод выборов списком или матрицей, перцептивные выборы (p), фото участников.
- Импорт списка или готовых выборов из XLSX и CSV (UTF-8 и Windows-1251).
- Персональные индексы, статусы, 14 групповых индексов, перцептивный блок.
- Общий и индивидуальный отчёты, социограммы взаимных выборов.
- Социограммы на SVG: перетаскивание узлов (раскладка сохраняется), масштаб, PNG, копирование в буфер.
- Чёрно-белый режим для печати: штриховки, пунктиры и разные обводки вместо цвета.
- Экспорт: печать и PDF, Word (.docx), Excel (.xlsx) с диаграммой и социограммами.
- Копирование любой таблицы отчёта в буфер (как таблица или картинка).
- Все тексты отчёта (пояснения, интерпретация, рекомендации) редактируются.
- Резервная копия всей базы одним JSON-файлом.

Формулы и правила описаны в [docs/METHOD.md](docs/METHOD.md).

## Запуск

Есть три варианта, возможности одинаковые.

**Программа для Windows с установкой** - `Linx_1.0.0_setup.exe`. Ставит программу для текущего пользователя
(права администратора не нужны), создаёт ярлык в меню «Пуск», удаляется через «Параметры → Приложения».
База хранится в папке `%APPDATA%\com.makulatury.linx\data`.

**Переносная программа без установки** - `Linx_1.0.0_portable.zip`. Распакуйте архив в любую папку
или на флешку и запустите `Linx\Linx.exe`. База хранится рядом, в папке `Linx\Linx-данные`, поэтому программу
переносят вместе с этой папкой. Если в эту папку нельзя записывать (например, программа лежит в `Program Files`),
программа предупредит об этом и временно сохранит базу в папке пользователя, как установленная версия.

Обеим программам интернет не нужен. База хранится так: `protocols\<id>.json` - по файлу на протокол,
`settings.json` - настройки и тексты отчёта. Где лежит база, показано в «Справке».
Выгрузки (Word, Excel, PNG, файл базы) сохраняются через окно «Сохранить как».

**Файл для браузера.** `dist/Linx.html` - откройте в Chrome или Edge двойным щелчком.
Данные хранятся в браузере (IndexedDB).

Во всех вариантах кнопка «Сохранить базу в файл» делает резервную копию, «Загрузить из файла» - восстанавливает.
Файл базы общий: его можно перенести между браузером и программами.

## Сборка

### Файл для браузера

Нужен Python 3.

```
python build.py
```

Собирает `dist/Linx.html`: все стили и скрипты встраиваются в один файл, внешних зависимостей нет.

### Программа для Windows (Tauri 2)

Один раз установить:

- Visual Studio Build Tools 2022 с компонентом «Разработка классических приложений на C++»
  (`winget install Microsoft.VisualStudio.2022.BuildTools`, затем в установщике выбрать этот компонент);
- Rust: `winget install Rustlang.Rustup`;
- Tauri CLI: `cargo install tauri-cli --version "^2" --locked`;
- Python 3 (для `build.py`). Node.js не нужен. WebView2 в Windows 10/11 уже есть.

Сборка обеих версий одной командой (из корня проекта):

```
python build_windows.py
```

Скрипт запускает `cargo tauri build` (а тот - `build.py`) и кладёт в папку `release/`:
`Linx_1.0.0_setup.exe` (установщик) и `Linx_1.0.0_portable.zip` (переносная версия: `Linx/Linx.exe`
и папка `Linx/Linx-данные`). Первая сборка идёт 5-10 минут и скачивает зависимости, при первой упаковке
скачивается NSIS. Папка `release/` в git не попадает.

Переносная версия устроена просто: если рядом с программой есть папка `Linx-данные`, база хранится в ней,
иначе - в `%APPDATA%`. Установленная версия такой папки не имеет.

Быстрый запуск для проверки без установщика: `cargo tauri dev` (из `src-tauri`).

Иконки собраны из `src-tauri/icons/linx.svg` (логотип «Тройка») командой `cargo tauri icon icons/linx.svg`
(лишние иконки для Android, iOS и macOS после этого можно удалить).

## Структура

| Файл | Назначение |
|---|---|
| `src/calc.js` | расчёты: матрица, индексы, статусы, рекомендации, индивидуальные социограммы (без DOM) |
| `src/storage.js` | слой хранения: IndexedDB или нативное хранилище `window.smNativeStore` |
| `src/importers.js` | чтение CSV и XLSX (свой разбор zip через DecompressionStream) |
| `src/texts.js` | шаблоны текстов отчёта с подстановками |
| `src/graph.js` | социограммы и круговая диаграмма на SVG, PNG |
| `src/export.js` | сборка DOCX и XLSX (свой zip, Office Open XML) |
| `src/tablekit.js` | таблицы отчёта для буфера обмена и PNG |
| `src/app.js`, `editor.js`, `report.js`, `textsview.js` | интерфейс |
| `src/fixtures.js` | контрольная группа для тестов и демонстрации |
| `src/native.js` | мост к программе для Windows: хранение на диске и окно «Сохранить как» (в браузере ничего не делает) |
| `src-tauri/` | программа для Windows: `src/lib.rs` - команды хранения и записи файлов, выбор папки базы; `tauri.conf.json` - окно и установщик |
| `build_windows.py` | сборка установщика и переносной версии в `release/` |

## Тесты

`tests/test.html` - проверка расчётов на контрольных примерах. Откройте через локальный сервер из корня проекта:

```
python -m http.server 8765
```

и затем `http://localhost:8765/tests/test.html`. В `tests/files/` лежат образцы файлов для проверки импорта.
